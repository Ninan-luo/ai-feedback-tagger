# 公开版改动说明

## 保留的原有能力

原版 v3 已包含读取人工编码样本、构建 few-shot 提示词、多级多标签编码、人工层级关系映射、问题上下文、失败重试、模型自报置信度与 Excel 导出。公开版继续以原有的 `EncoderConfig`、`DataLoader`、`MultiLevelLabelLearner`、`MultiLevelTextEncoder` 和 `EncodingPipeline` 组织代码。

## 为公开展示补充的内容

- 移除硬编码凭据、业务名称和原代理地址，修正 `OPENAI_API_KEY` 环境变量读取。
- 模型名称改为必填，移除未使用的 Anthropic 依赖。
- 补充虚构 CSV 示例和离线模拟客户端，支持不配置密钥查看完整处理流程。
- 让示例总数上限真正生效，添加输入参数检查。
- 人工层级表作为唯一标签来源，拒绝同一二级标签映射到多个一级标签。
- 检查返回结构、标签合法性与置信度枚举，非法结果重试后标记失败。
- 增加人工复核标记，处理空输入，修正将失败记录统计为成功的问题。
- 保护输入与既有输出文件，对导出文本作公式注入防护。
- 添加中文说明和无网络测试。

这些是公开发布时的整理与维护，不应倒推为原业务项目当时已经实现的功能。仓库不发布历史业务数据和内部报告，也不把模拟输出用作模型效果证据。
